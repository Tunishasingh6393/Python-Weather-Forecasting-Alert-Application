# Weather Forecast & Alert Application - Project Guide

## Project Summary
This project is a professional-grade weather monitoring system designed for portfolio use. It features a complete pipeline from data ingestion to risk alerting and professional visualization.

## Key Components
1. **Core Python Tool (`python_project/`)**: A modular CLI application for weather analysis and automated report generation.
2. **Full-Stack Web Dashboard**: A modern React/FastAPI-style dashboard built with the "High Density" theme, featuring interactive Recharts and real-time alerts.
3. **Rule Engine**: A deterministic system on the backend that analyzes hourly forecast data to trigger heat, wind, and rain alerts.

## How to Run the Python CLI
1. Navigate to the project root.
2. Install requirements: `pip install -r python_project/requirements.txt`.
3. Run main script: `python python_project/main.py`.

## How to Run the Web Dashboard
1. Run `npm install`.
2. Run `npm run dev`.
3. Open `http://localhost:3000`.
