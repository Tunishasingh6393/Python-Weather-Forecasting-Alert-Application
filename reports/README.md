# Automated Weather Reports 📝

This folder stores the "Truth Signals" generated by the system—automated reports that summarize weather events and risks.

### 🔎 Report Types

#### 1. Quick Summary (.txt)
A human-readable text file generated every 6 hours or when an alert is triggered.
**Example Structure:**
```text
WEATHER ANALYSIS REPORT: LONDON
Generated at: 2024-05-05 10:30
------------------------------
Current Temp: 12°C
Alerts: ⚠️ RAIN ALERT (80% chance)
------------------------------
Summary: Carry an umbrella for the evening commute.
```

#### 2. Historical Log (.csv)
A time-series log used for long-term trend analysis and machine learning training.
**Data Columns:** `timestamp`, `city`, `temp`, `wind`, `risk_level`, `alert_code`.
